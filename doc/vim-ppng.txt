1. INTRODUCTION                                     *vim-ppng-introduction*

vim-ppng is a Vim/Neovim plugin that enables instant text sharing between
editors via Ppng Server (https://ppng.io). Send text from one editor and
receive it in another using simple commands.

Features:
- Send buffer content or visual selection to Ppng Server
- Receive text from Ppng Server into a new buffer
- History management for quick access to recently used URLs
- Optional encryption with Vim's own |:X| (|vim-ppng-encryption|)
- Hard-to-guess random paths with the {random} token
- Works with both Vim 8.0+ and Neovim 0.5+
- Customizable server URL, path, and timeout settings

==============================================================================
2. REQUIREMENTS                                     *vim-ppng-requirements*

- Vim: 8.0 or later
- Neovim: 0.5 or later
- curl: Required for HTTP communication with Ppng Server
- Encryption (|:PpngSend!|, |:PpngReceive!|): Vim with |+cryptv|, and
  |+sodium| for the default 'xchacha20v2'. Neovim has no |:X|, so it cannot
  encrypt.

3. COMMANDS                                            *vim-ppng-commands*

                                                              *:PpngSend*
:PpngSend [path]
        Send the entire buffer content to Ppng Server.
        If [path] is provided, it will be used as the URL path or full URL.
        If [path] is omitted, you will be prompted for input.

        The command supports visual selection:
        - Select text in visual mode and run :PpngSend to send only the
          selected text.

        If [path] is {random}, a new random path is used (see
        |vim-ppng-random|).

        Examples: >
            :PpngSend mytext
            :PpngSend https://ppng.io/custom-path
            :'<,'>PpngSend shared
            :PpngSend {random}
<
                                                             *:PpngSend!*
:[range]PpngSend! [path]
        Like |:PpngSend|, but the text is encrypted before it is sent.
        The key is asked twice with |inputsecret()|. If the keys differ or
        the key is empty, nothing is sent. See |vim-ppng-encryption|.
        In Neovim, or in Vim without |+cryptv|, an error is shown and
        nothing is sent.
                                                           *:PpngReceive*
:PpngReceive [path]
        Receive text from Ppng Server and display it in a new buffer.
        If [path] is provided, it will be used as the URL path or full URL.
        If [path] is omitted, you will be prompted for input.

        The received text will be opened in a new buffer with these settings:
        - buftype=nofile (not associated with any file)
        - bufhidden=wipe (buffer is deleted when hidden)
        - noswapfile (no swap file created)

        Examples: >
            :PpngReceive mytext
            :PpngReceive https://ppng.io/custom-path
<
                                                          *:PpngReceive!*
:PpngReceive! [path]
        Like |:PpngReceive|, but the received data is decrypted with a key
        asked with |inputsecret()| (before waiting for the sender).
        A wrong key, unencrypted data, or data encrypted with a weak method
        ('zip', 'blowfish') is refused and nothing is shown.
                                                           *:PpngHistory*
:PpngHistory
        Show a list of recently used URLs and interact with them.
        You can select an entry from the history and choose to send to or
        receive from that URL, plain or encrypted.

        History entries are stored with the most recent first, up to the
        maximum specified by |g:ppng_history_max|.

                                                      *:PpngClearHistory*
:PpngClearHistory
        Clear all entries from the history.

4. FUNCTIONS                                          *vim-ppng-functions*

These functions provide programmatic access to vim-ppng functionality.

                                                          *vim_ppng#send()*
vim_ppng#send({mode}, {path} [, {opts}])
        Send text to Ppng Server.

        Parameters:~
            {mode}  String - 'normal' (entire buffer) or 'visual' (selection)
            {path}  String - URL path or full URL (empty string for prompt)
            {opts}  Dict   - optional. 'encrypt': v:true to encrypt,
                             v:false to send plain text. Without the key,
                             |g:ppng_encrypt| decides.

        Returns:~
            Dictionary with keys:
            - ok:    Boolean - v:true on success, v:false on failure
            - url:   String  - Full URL where text was sent
            - error: String  - Error message (empty on success)

        Examples: >
            " Send entire buffer
            let result = vim_ppng#send('normal', 'mytext')
            if result.ok
                echo 'Sent to: ' . result.url
            endif

            " Send visual selection
            let result = vim_ppng#send('visual', '')
<
                                                       *vim_ppng#receive()*
vim_ppng#receive({path} [, {opts}])
        Receive text from Ppng Server.

        Parameters:~
            {path}  String - URL path or full URL (empty string for prompt)
            {opts}  Dict   - optional. 'encrypt': v:true to decrypt.

        Returns:~
            Dictionary with keys:
            - ok:    Boolean - v:true on success, v:false on failure
            - url:   String  - Full URL from which text was received
            - error: String  - Error message (empty on success)

        Example: >
            let result = vim_ppng#receive('mytext')
            if !result.ok
                echo 'Error: ' . result.error
            endif
<
                                                 *vim_ppng#clear_history()*
vim_ppng#clear_history()
        Clear all entries from the history.

        This function has no parameters and no return value.

        Example: >
            call vim_ppng#clear_history()
<

5. OPTIONS                                              *vim-ppng-options*

                                                           *g:ppng_server*
g:ppng_server
        The base URL of the Ppng Server to use.

        Default: 'https://ppng.io'

        Example: >
            let g:ppng_server = 'https://ppng.io'
<
                                                             *g:ppng_path*
g:ppng_path
        The default path to use when no path is specified.
        Use 'random5char' to let the server generate a random 5-character
        path automatically.

        Default: 'random5char'

        Set it to '{random}' to get a new random path in the prompt each
        time you send (see |vim-ppng-random|).

        Example: >
            let g:ppng_path = 'mydefault'
            let g:ppng_path = '{random}'
<
                                                          *g:ppng_timeout*
g:ppng_timeout
        Timeout in seconds for curl operations.

        Default: 30

        Example: >
            let g:ppng_timeout = 60
<
                                                      *g:ppng_history_max*
g:ppng_history_max
        Maximum number of history entries to store.
        Set to 0 to disable history tracking.

        Default: 10

        Example: >
            let g:ppng_history_max = 20
<
                                                          *g:ppng_encrypt*
g:ppng_encrypt
        When non-zero, |:PpngSend| and |:PpngReceive| encrypt and decrypt
        as if "!" was given.

        Default: 0

                                                      *g:ppng_cryptmethod*
g:ppng_cryptmethod
        The 'cryptmethod' used by |:PpngSend!|: 'xchacha20v2' or
        'blowfish2'. The obsolete 'xchacha20' is not used. The receiver detects the method from the data.
        Empty means 'xchacha20v2' when Vim has |+sodium|, else 'blowfish2'.
        Use 'blowfish2' when the receiver's Vim has no |+sodium|.

        Default: ''

6. EXAMPLES                                            *vim-ppng-examples*

Basic Usage~

1. Send entire buffer to server:
>
    :PpngSend
<
   Enter a path when prompted, e.g., "mytext"

2. Receive text from server:
>
    :PpngReceive mytext
<

Visual Selection~

1. Select text in visual mode (v or V)
2. Run:
>
    :'<,'>PpngSend shared
<

Using History~

1. After sending or receiving, view history:
>
    :PpngHistory
<
2. Select an entry and choose send/receive action

Configuration Example~

In your .vimrc or init.vim:
>
    " Use custom Ppng Server
    let g:ppng_server = 'https://ppng.io'

    " Set default path
    let g:ppng_path = 'vim-share'

    " Increase timeout for slow connections
    let g:ppng_timeout = 60

    " Store more history entries
    let g:ppng_history_max = 20

    " Key mappings (optional)
    nnoremap <Leader>ps :PpngSend<CR>
    vnoremap <Leader>ps :PpngSend<CR>
    nnoremap <Leader>pr :PpngReceive<CR>
    nnoremap <Leader>ph :PpngHistory<CR>
<

Programmatic Usage~
>
    " Send current buffer and check result
    function! MyCustomSend()
        let result = vim_ppng#send('normal', 'mypath')
        if result.ok
            echo 'Successfully sent to: ' . result.url
        else
            echoerr 'Failed: ' . result.error
        endif
    endfunction
<

7. ABOUT PPNG SERVER                                    *vim-ppng-about*

Ppng Server is a service that enables instant data transfer using HTTP.
When you send data to a path, the server holds the connection open until
someone requests data from the same path. This creates a simple, real-time
pipe between two endpoints.

Default Server: https://ppng.io

How it works:
1. Sender uploads data to https://ppng.io/path
2. Server waits for a receiver
3. Receiver downloads from https://ppng.io/path
4. Data is transferred directly through the server

Security Note:
- Without "!" data is transferred in plain text; use |:PpngSend!|
- Anyone with the URL path can access the data
- Use random paths for sensitive data (|vim-ppng-random|)
- Consider running your own Ppng Server for private use

You can run your own Ppng Server:
https://github.com/nwtgck/ppng-server

8. ENCRYPTION                                        *vim-ppng-encryption*

|:PpngSend!| and |:PpngReceive!| use Vim's own file encryption (|:X|,
'cryptmethod', 'key').

Sending:~
1. The key is asked twice with |inputsecret()|.
2. The text gets one header line: >
       vim-ppng-crypt:1:{number of lines}:{sha256 of the text}
<3. It is written to a |tempname()| file (mode 0600) from a scratch buffer
   with 'key' and 'cryptmethod' set. The scratch buffer has no swap file,
   no undo, and no autocommands run.
4. The file is sent with "curl --data-binary" and then deleted.

Receiving:~
1. The key is asked once.
2. The data is downloaded with "curl -o" into a 0600 temp file.
3. The file must start with a VimCrypt header of 'blowfish2' or
   'xchacha20v2'; otherwise nothing is shown (zip, blowfish and the
   obsolete xchacha20 are refused).
4. It is read with the key, the header is checked, and the text is opened
   in a new scratch buffer. The temp file is deleted.

Wrong key:~
'xchacha20v2' refuses a wrong key by itself (E1200). 'blowfish2' would
silently give garbage; the sha256 in the header catches that. Either way the
error is "Wrong key or corrupted data" and nothing is shown.

The key:~
The key is not added to any history, viminfo, variable, register or
message. 'key' is cleared before the scratch buffers are wiped. Temp files
are deleted even when encryption or curl fails.

Not supported:~
Neovim has no |:X|. In Neovim, and in Vim without |+cryptv|, the commands
show an error and send or receive nothing. 'xchacha20v2' needs |+sodium|.

                                                         *vim-ppng-random*
Random paths:~
The token {random} as [path] of |:PpngSend| (or as |g:ppng_path| for the
prompt) is replaced with 24 characters from /dev/urandom (about 120 bits),
using "abcdefghijkmnpqrstuvwxyz23456789". The URL is shown before curl
waits for the receiver; pass the path to the receiver separately.
